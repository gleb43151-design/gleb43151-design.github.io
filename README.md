# Победи ИИ — проверь свою память

Веб-игра и сайт индивидуального проекта «Память человека и искусственного интеллекта: сравнительное исследование» (МБОУ «СОШ № 67» г. Владивостока, автор — Толмачёв Глеб, 10 «А»).

## Что это

Сайт позволяет сравнить свою память с архивными ответами языковой модели на одинаковых текстах:

- **Основная игра** — чтение текста (300/900/1800 слов), пауза-отвлечение 30 секунд, десять вопросов, разбор с эталонами и предложениями-основаниями.
- **Тест объёма рабочей памяти** — мини-опыт: сколько цифр вы воспроизведёте подряд.
- **Мифы о памяти** — десять утверждений о памяти человека и ИИ с разбором по исследованиям.

## Честные правила

- В режиме «По памяти» человек отвечает без текста, модель отвечала с текстом — это сравнение памяти с инструментом, у которого источник под рукой.
- Ответы модели — архивные: получены заранее (18.10.2026, модель gpt_6_luna, один запуск на карточку, текст и вопросы без ключа ответов) и не пересчитываются на ходу.
- Результаты хранятся только в памяти браузера во время сессии и никуда не отправляются.

## Технологии

HTML, CSS, JavaScript без сторонних фреймворков. Банк заданий (7 карточек) отделён от логики интерфейса.

## Структура

- `index.html` — разметка экранов
- `style.css` — дизайн-система
- `app.js` — логика: чтение, вопросы, оценка ответов, тест памяти, мифы
- `data1.js`, `data2.js`, `data3.js` — банк карточек с текстами, вопросами, ключами и архивными ответами модели
